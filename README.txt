# Birthday Surprise Website — FREE Template

## Apa yang kau boleh edit
Semua benda utama boleh tukar dalam `config.js`:
- Nama penerima
- Nama kau
- Password
- Semua ayat
- Gambar
- Lagu

## Cara letak gambar
Masukkan gambar ke:
`assets/images/`

Nama ikut config:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg

Kalau nak tambah/kurang gambar, edit senarai `photos` dalam `config.js`.

## Cara letak lagu
Masukkan fail MP3 ke:
`assets/music/`

Namakan `song.mp3`, atau tukar nama dalam `config.js`.

Nota: browser biasanya block autoplay audio. Sebab tu website guna butang Play.

## Cara test
Double-click `index.html` untuk cuba buka di browser.

## Cara publish FREE
Paling mudah guna GitHub Pages:
1. Buat akaun GitHub.
2. Create new repository.
3. Upload semua fail dalam folder ini.
4. Pergi Settings → Pages.
5. Pilih Deploy from branch → main → /root.
6. Save.
7. GitHub akan beri link website.

## Penting
Password pada website ini ialah password screen biasa di bahagian depan (bukan sistem keselamatan sebenar). Untuk birthday surprise, ia sesuai.

Kalau kau nak tukar design, edit `style.css`.
